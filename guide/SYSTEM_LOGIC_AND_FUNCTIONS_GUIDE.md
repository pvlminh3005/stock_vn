## 1. KIẾN TRÚC TỔNG THỂ HỆ THỐNG

Stock RT là nền tảng phân tích kỹ thuật, cơ bản và ra quyết định giao dịch chứng khoán Việt Nam thời gian thực theo hướng **Bảo toàn vốn (Capital Preservation First)**.

```
                    ┌────────────────────────────────────────────────────────┐
                    │               CLIENT (Frontend / Vanilla JS)           │
                    │  Lightweight Charts, Dynamic Decision Hero, Sổ Lệnh    │
                    └───────────────────────────┬────────────────────────────┘
                                                │ REST API (JSON)
                    ┌───────────────────────────▼────────────────────────────┐
                    │              BACKEND WEB SERVER (Python)               │
                    │  BaseHTTPRequestHandler + PIN Auth + CSP Protection    │
                    └───────────────────────────┬────────────────────────────┘
                                                │
         ┌──────────────────┬───────────────────┼──────────────────┬─────────────────┐
         ▼                  ▼                   ▼                  ▼                 ▼
   Controllers        Domain Engines       Data Providers      DB Layer        Schedulers / Bot
  (Stock, Market,    (Decision, Tech,     (Entrade, VCI,      (MongoDB         (Telegram Bot,
   Screener,          Valuation, Risk,     Simplize, CafeF,    Atlas +          Portfolio Worker,
   Portfolio)         Regime, Bundler)     Gov, VnExpress)     SQLite)          Screener Worker)
```

**Nguyên tắc cốt lõi (Guardrails):**
1. **Không Hardcode/Mock Data:** 100% số liệu thị giá, khối lượng, tỷ lệ %, chỉ số tài chính được nạp từ nguồn dữ liệu thật (Entrade, VCI, Simplize, CafeF, GSO). Nếu thiếu dữ liệu, hiển thị trung thực `"Dữ liệu chưa ghi nhận"`.
2. **Không dùng công thức ngón tay cái tĩnh cố định:** Không gán cứng tỷ lệ cắt lỗ/chốt lời (như -5%, +7%) mà tính toán động 100% theo nến Fractal Pivots (S1/R1), ATR14, và biên độ từng sàn (HOSE: 7%, HNX: 10%, UPCoM: 15%).
3. **Cơ chế 3 tầng dữ liệu bảng giá:** RAM Cache (45s) -> Entrade Intraday Multi-threading -> MongoDB Atlas Snapshot (chống chặn IP Cloud).

## 6. BACKEND - DATABASE LAYER, DOCUMENT MODELS & MIGRATION (`backend/db/`, `backend/models/`)

Hệ thống hỗ trợ kiến trúc lưu trữ dữ liệu kép **(Hybrid Database Engine)**:

- `db.py`:

Khi code truy cập `KNOWN_STOCK_SECTORS[sym]` hoặc `.get()`, class này tự động nạp danh bạ 1,626 mã từ MongoDB Atlas và gọi `get_dynamic_sector` để phân loại ngành thông minh, xóa bỏ hoàn toàn việc gán cứng (hardcode) danh sách mã.
- `urls.py`:
  - `build_entrade_chart_url(type, params)`: Tạo URL gọi API nến của Entrade (hỗ trợ cả chứng khoán cơ sở `stock` và chỉ số `index`).

  - `build_cafef_search_url(ticker)`: Tạo link tìm kiếm tin tức doanh nghiệp trên CafeF.

## 12. TỔNG KẾT BẢO TOÀN VỐN & NGUYÊN TẮC HOẠT ĐỘNG

Toàn bộ hệ thống logic trên phối hợp nhịp nhàng theo một chu trình khép kín:
1. **Quản trị môi trường & cách ly dữ liệu (Environment Loader):** Tách biệt rạch ròi cụm database Development và Production, chống ghi đè nhầm lẫn.
2. **Lọc cơ hội (Screener Engine & Top T+ Bar):** Phát hiện dòng tiền thông minh nhập cuộc thời gian thực mà không bị giới hạn IP trên Cloud.
3. **Thẩm định đa chiều (Stock Controller):** Kết hợp đồng thời Kỹ thuật (Technicals), Cơ bản (Valuation), và Xu hướng thị trường (Regime).
4. **Quản trị rủi ro khắt khe (Risk Engine):** Đo lường tâm lý Fear & Greed, rủi ro pháp lý/BCTC, và xây dựng kịch bản Bull/Bear với tỷ lệ Net R:R tối thiểu 1:1.3.
5. **Ra quyết định dứt khoát (Decision Hero Card):** Cung cấp hành động rõ ràng (MUA/BÁN/GIỮ/CHỜ), vùng giá vào lệnh, điểm cắt lỗ kỷ luật và mục tiêu chốt lời động 100% theo nến Fractal Pivots & ATR14.
6. **Giám sát tự động (Portfolio Scheduler & Telegram Bot):** Quét định kỳ 15 phút bảo vệ vị thế đang nắm giữ, gửi cảnh báo vi phạm cắt lỗ tức thời và báo cáo tổng kết SuperTrend chốt phiên EOD 15:02 cho nhà đầu tư.
7. **Bảo vệ hạ tầng liên tục (CI/CD Keep-Alive):** GitHub Actions tự động đánh thức server lúc 8:50 sáng đảm bảo bot quét nổ sóng sớm ngay từ phiên ATO.
